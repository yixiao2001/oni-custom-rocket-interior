[h1]自定义火箭舱内空间 / Custom Rocket Interior[/h1]

[b]━━━━━━ 中文 ━━━━━━[/b]
自定义《缺氧》火箭舱室大小、墙体材质与内部装修规则。需要《眼冒金星！》DLC。
[list]
[*]内部世界宽高各 12–96 格，四种墙体材质：钢 / 火成岩 / 中子质 / 玻璃
[*]火箭内部全图去迷雾，出入口、四个固定气液端口与控制站按新布局定位
[*]设置界面支持英文和简体中文：主菜单 → 模组 → Custom Rocket Interior → 选项
[/list]
[b]v0.4.0：可拆内墙与自由装修[/b]
[list]
[*]可正常拆除火箭舱壳和窗砖，包括中子质；顶墙也可从舱内施工
[*]四个自带气液端口、舱门和控制站不会被此选项解锁
[*]可建造的气体、液体、固体货舱输入输出组件和电力插座，可依附舱内任意自建实心砖，包括普通砖、隔热砖、金属砖和窗砖
[*]保留旋转方向与支撑要求；不支持悬空、天然格、网格砖或透气砖
[*]拆去支撑后组件停工，电力插座断开火箭电路；补回有效支撑后恢复
[/list]
[b]使用说明[/b]
[list]
[*]“允许拆除火箭内墙”和“输入输出组件可依附任意实心砖”默认开启，修改后需要重启；已有舱室读档后也能使用
[*]尺寸和墙体材质只影响新建火箭，不改写已有舱室布局
[*]拆墙不会扩大内部世界，也不会移动四个固定端口；关闭开关不会恢复已经拆除的墙
[*]建议先建好替代外壁再拆旧墙，以保持气密性
[/list]

[b]━━━━━━ English ━━━━━━[/b]
Customize rocket interior size, wall material and construction rules. Requires the Spaced Out! DLC.
[list]
[*]Interior world width/height: 12–96 tiles; Steel / Igneous Rock / Neutronium / Glass walls
[*]Full interior fog reveal; door, fixed gas/liquid ports and control station follow the resized layout
[*]English/Simplified Chinese options: Main Menu → Mods → Custom Rocket Interior → Options
[/list]
[b]v0.4.0: Removable walls and rebuilt supports[/b]
[list]
[*]Deconstruct hull/window tiles, including Neutronium; ceilings can be reached from inside
[*]The four fixed gas/liquid ports, interior door and control station stay protected
[*]Player-built gas/liquid/solid cargo fittings and the power plug can use any built solid tile inside a rocket, including ordinary, insulated, metal and window tiles
[*]Rotation and support requirements remain; natural cells, mesh/airflow tiles and empty space are excluded
[*]Removing support stops cargo exchange and disconnects the power plug; rebuilding valid support restores operation
[/list]
[b]Notes[/b]
[list]
[*]Both new Construction options are enabled by default. Changing them requires a restart; existing interiors gain these features when loaded
[*]Size/material settings affect newly created interiors only
[*]Removing walls does not expand the world or move fixed ports. Disabling deconstruction does not restore removed walls
[*]Build a replacement enclosure before removing the old one to keep it airtight
[/list]
